# 方坤专业知识库与 Codex 交接包 R4

这是一个范围明确的知识与实现交接版本，不是“全部运动科学已穷尽”，也不是 App 已安装或模型已训练。

本次交付：30条继承决策规则、28张新增可检索操作卡、9组参考条目（含内部多个场景）、15项来源、20个继承教学案例、14个已执行模块测试。细分出处和访问限制均可追溯。

阅读顺序：`CODEX-TASK.md` → `knowledge/专业操作手册.md` → `knowledge/reference-ranges.json` → `docs/实现合同.md` → `docs/验收案例.md`。

## 范围与发布边界
- 支持研究/实现：健康成人，初学跑步到400–10000m专项讨论、一般力量/肌肥大/爆发力、跑力协同、疲劳复盘、运动营养、个人基线、长期修订。
- 精英短跑参考作为背景，不能自动迁移400m；800/1500、长跑资料有摘要访问限制，精确课表需已有教练方案或后续专项证据。
- 不包含：医疗、康复处方、未成年人/妊娠等特殊人群自动计划、个体疾病诊断、完整食物数据库、现成训练动画或3D资源。
- 补剂剂量、临床REDs算法、运动中精确补给处方未列为自动执行能力。这些不是暗中缺省，而是明确禁用范围。
- 本包把知识、产品规则、研究范围、候选模板分开。能检索不等于适用；能算术换算不等于处方批准。

## 运行
Node.js 18+：`node --test runtime/kb.test.mjs`。无网络、无第三方依赖、无模型费用。
`runtime/kb.mjs`提供任务过滤、缺项提示、可比性检查、参考量换算、同量纲负荷比、营养部分和。它是参考模块，不是完整教练引擎。
用法参见`runtime/example.mjs`。输入字段仍需App校验身份、日期、量纲、修订号；检索匹配不授权执行。

## 验证范围
14个新模块测试通过；继承教学案例是验收规范，不是已经在App跑过。App端接入、浏览器、数据持久化、多周模拟和专业人员评审均未完成。本包没有修改用户数据或部署应用。
`archive`仅保留旧版审计和R2原型，不要直接导入生产。R4不是在旧版基础上谎称修复了所有代码缺陷。

## 科学工作方法
定向文献核对，不是系统综述或专业认证。摘要未提供的信息不补写为结论。来源差异保留，定期复查更正。通过literature-review技能辅助组织检索；方法工具引用：Kassis T, Agarwal V, He Y, Patel D, Brueckner AM (2026), Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents, arXiv:2609.00065, https://doi.org/10.48550/arXiv.2609.00065 。该工具论文不是运动处方证据。
