# 候选模板：先绑定批准方案，再给用户执行

这些模板是产品结构，不是新增的通用运动处方。实例参数未给出时不由模型自由补齐；模板预览与执行授权分开。

|模板|适用与输入|结构|主要观察与退出|
|---|---|---|---|
|走跑起步|成人新手、无已知活动限制、当前活动史|可引用NHS渐进走跑课程；起始步行5分钟、跑间休息日；具体阶段链接原课程|能否舒适完成、次日反应；不适停止，不能保证9周达标|
|速度质量|短跑经验、目的、批准课、计时/场地|一般准备→专项准备→加速或最高速段→整理；距离/次数/组休取批准课|技术或表现明显下降，不通过缩短组休追赶时间|
|800/1500专项|项目、近期锚点、训练阶段|热身→目标明确的间歇→整理；每段速度、恢复方式显式|完成并不等于达到训练目的；速度与恢复改变需重新解释|
|耐力基础|当前历史、可用时间、批准强度锚点|匹配个人轻松强度的已批准跑课；时长取现有计划|主观用力、完成稳定性、环境；不自动加每周10%|
|一般力量|目标、经验、器械、限制|按蹲/髋/推/拉等目标选择动作；每项记录组次、负重、组休、动作质量|不以统一3×8替代目标；负荷规则来自批准课|
|爆发力辅助|动作经验、跑力优先级、已批准动作|质量优先，快速意图，体力消耗不作为唯一目标|表现/技术下降与跑步关键课冲突需调整|
|短时间热身|运动类型、主课、5/15/30/40分钟预算|一般升温→动态活动→专项预备；预算内选择既有方案|若不能容纳关键准备，调整主课，不压缩为形式热身|
|漏练重排|原计划、漏练原因、未来时间|提出保留关键课/替换/取消的候选，展示差别|不补偿性堆量；用户确认才写入|
|饮食日计划|目标、全天训练、体重、偏好、可用食物、既往耐受|先确定选用参考及理由→每日目标候选→餐次分配→食物替换→核对总和|未知营养显示部分和；不凭名字虚构完整营养|
|训练前后饮食|训练时点、既往耐受、现有餐次|在全天目标内安排可用食物与时间；避免重复加算|无剂量来源不凭空生成精确每小时碳水/钠；可先展示已有批准补给方案|

## 可核算的说明示例
60kg成人选择某蛋白参考1.2–1.6 g/kg/day时，算术范围为72–96g/day。这只说明换算，必须先确认该来源的适用情境，不能因为能算出来就认定这是用户目标。
饮食有三项蛋白记录10g、未知、0g：展示已知10g，1项待补；不能宣称全天仅10g，也不能把已知值全部隐藏。
28天每日同一负荷10：7日均值10、28日均值10，比值1；不是70/10=7。缺记录时不当休息日。
