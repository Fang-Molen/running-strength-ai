# V74 配套参考人物：来源、许可与限制

`athlete-male.glb`、`athlete-female.glb` 由本仓库已有 `athlete.glb` 离线派生，模型资源沿用 CC0-1.0；原始来源、MakeHuman 及授权链见 `athlete-LICENSE.md`。Three.js 沿用自身 MIT 许可。没有下载外部人物或上传身体数据。

修改：统一鞋色与材质、嵌入纹理压缩到不超过 1024 像素、女性参考模型适度调整肩髋轮廓。沿用原有 53 骨骼、蒙皮、4 个外形混合通道和动作库，生成脚本为 `tools/character/complete-avatars.py`。各模型 JSON 包含来源哈希和派生文件哈希。

这两个模型是成人视觉参考，未验证个人脸型或真实体型；共用骨长和动作，不代表经过专业认证的男女生物力学差异。衣物未做独立布料模拟。形态参数不用于推算体脂、肌肉量或制定训练处方。

几何检查只排查非有限坐标、骨骼及资源缺失、异常越界；不能替代教练对动作安全、关节角度和器械接触的逐项审查。
