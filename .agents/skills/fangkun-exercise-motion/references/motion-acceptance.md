# 动作验收标准与优先级

P0: `back-squat` 杠铃深蹲、`rdl` 罗马尼亚硬拉、`bss` 保加利亚分腿蹲、`bb-row` 反握杠铃划船、`bb-ohp` 杠铃推举、`calf` 站姿提踵。IDs 摘自当前 R2 `complete-153-inventory.csv`。

| 检查点 | 要求 |
|---|---|
| 视觉身份 | 使用最终新版男女 GLB，每个动作脸、发型、衣服、鞋一致 |
| 角色皮肤 | 确认 GLB `skins`、骨骼索引、权重存在，不能“只有 armature” |
| 姿势 | 起始、中间、末位与动作名真实一致 |
| 物理接触 | 落地、脚跟、杠铃/哑铃/凳面、手部握点稳定，无严重漂浮或穿模 |
| 时间 | 循环头尾连续、没有瞬间跳变；慢放仍合理 |
| 专业审校 | 至少由熟悉该动作的人审核每组关键点；有伤病风险的教学语句不宣称医疗效果 |
| 2D | 从**同一新角色真实 3D 动作**采样，4–6帧，绑定 clipId/秒数/modelSHA256 |
| 合规 | 模型、贴图、动作的商业使用许可证逐项确认；没有确证不得上线 |
| 性能 | 真正 iPhone Safari+桌面 WebGL，记录初次加载、帧率、内存、断网缓存状态 |

先在 six × 2 上验收，再增量覆盖其余动作。对无完整 3D 的动作， UI 必须明确 `图文说明 / 动作演示待制作`；不调用旧角色或冒充动态3D。标签肌肉图只是主辅肌肉区域说明，不代表实时 EMG 测量。
