# 方坤 R10：R9 验收问题改进版

基于上一轮交付的 R9 源码，参考用户提供的 R9 验收报告继续修改。用户允许相对放宽守卫；沿用“暂时不用测试、不调用 Gemini”的要求。本轮没有接入或选择新的模型供应商，没有发布。

这是代码改进交付，不是验收通过证明。已做 TypeScript 静态类型检查；未执行回归测试、构建、浏览器测试或真实模型评测。新增回归用例和更新断言均待执行。R8 的通过记录、外部 R9 的评分都不能作为 R10 的验证结果。

## 守卫如何放宽

- 建议缺变量标签、数字前后值、固定停止/复查句式时，记录结构提示，保留候选。排期、技术练习和减量不必强行套数字模板；多变量候选提示复核。
- 区分通用范围、示例、条件建议和已完成的个人事实，减少 RPE 范围、建议配速、假设恢复状态被误认为事实的拦截。
- 不再一律禁止讨论缩短休息或小幅进阶；条件候选可以说明前提、取舍、停止和反馈。已知疼痛、急症、未解决的来源冲突仍保留约束。
- 缺少两种解释、反证句式、固定转诊措辞或长度不合模板，不再单凭这些原因替换整段回答。
- 不合格的事实或结论仍会被拦截；拦截后改用当前可核对记录及相关问题兜底，避免只显示空模板。病后、高温、营养与月经线索使用相应主题说明。
- 守卫放宽不授权写课表、不把候选当作批准执行，不允许复活作废事实或声称医疗诊断、痊愈保证。

## 教练内容与展示

补充手册主题同义表达与数字规则，涵盖膝盖刺痛、年龄/初中生、35 度天气、低热量节食、AU 等表达；降低“手表”误占心率主题的权重，保留原训练机理回答入口。资料仍来自用户手册，本轮没有独立核验参考文献或训练模型参数。

摘要统一小数精度，不再在每条模型回答前自动堆叠全部分段与恢复数字；来源详情折叠显示。追问模式缺少问题时补充一个能推进决定的问题。新增“使用说明与免责声明”和逐条回答反馈：反馈只保存在本机，可由用户导出自己的 JSON 文件，不自动上传或通知他人。

## 明确保留的急救行为

高温/大太阳/暴晒环境中的意识不清、迷糊、说话异常等优先输出停止运动、联系 120 或当地急救、旁人协助降温及意识不清不强行喂水。急症回答替换训练分析，不能附带继续训练建议。否定、知识咨询和假设表达在词法层区分。该规则仍不是医疗诊断，也不是完整的语义识别系统。
