# 问答与受信联网续接计划

基线：GitHub master `1d57de0d413f365ff3ece4b63f859f94298706ba`；独立分支 `codex/coach-qa-repair`。
交接补丁 16 个文件逐一 SHA-256 核对后应用，旧 R6 工作目录与用户数据保留。

1. 一般知识与个人问题分流；疼痛口语、否定范围和列表编号修复，保留数值与安全守卫。
2. 同源快照创建与撤回：现有真实认证、服务器归属、明确同意、来源标记、不可变版本、短时引用。
3. 复用持久 PostgreSQL 费用账本，配置缺失/历史费用未核对时关闭付费派发；不假定历史费用为零。
4. 接入客户端的资料预览、逐次同意、引用请求和取消；账号切换、更正、权限变化使旧响应失效，本地正文一直保留。
5. 现有 Cloudflare 静态站通过服务器固定配置的受信后端适配；增加显式 Node 服务构建目标与同源 API 路由，默认静态构建保留。
6. 用真实 HTTP 路由、临时 SQL 数据库和替身 provider 验证完整链路；运行必要局部测试后集中回归、类型检查、构建、桌面/手机交互及生产预览。
7. 提交独立 PR，列出前后实际输出、测试证据、生产配置与回滚；不自动合并、部署或调用付费模型。

已知边界：本地浏览器资料并非服务端设备验真事实；只允许在身份与同意核验后作为用户申报资料参与受限解释。研究/模型专业能力与工程连通性分别报告。
