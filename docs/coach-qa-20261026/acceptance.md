# 问答与联网接续验收

基线 `1d57de0d413f365ff3ece4b63f859f94298706ba`，GitHub master 已在线核实；交接包的16文件补丁逐一校验后接续。旧 R6 工作目录、UI、用户记录与私人计划均保留。新增代码没有默认导入 V4 或跨账号复制历史。

## 已实现的链路

一般知识直接本地回答；个人问题先给本地分析，再单独提供「核对资料并联网解释」。预览阶段不联网。用户同意后：配置检查 → 真实登录核验 → 持久、按账号归属的短期快照与同意记录 → 仅引用请求 → 预算预留与幂等派发 → 数值／单位／来源／安全校验 → 显示解释并撤回本次快照。同意、引用和浏览器开关都不能替代服务端身份与预算验证。

浏览器来源明确降级为用户申报。第一版联网适配只接受有限标量，不把时长伪装成一次已完成连续跑，不把健康记录变成训练次数，也不猜测阈值和配速。原来的多模块本地分析仍保留完整来源。

新增 GET 诊断能区分缺路由、服务关闭、缺密钥、认证／持久存储未就绪、历史费用未核和策略未核。默认静态构建保留，另有实际 Node 后端构建及现有 Cloudflare 同源转接，见 [运行与回滚](runtime-and-rollback.md)。
