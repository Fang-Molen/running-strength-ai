### 命令

```bash
python3 tools/apply_new_modules.py --repo /path/to/codex/current-repo
python3 tools/apply_new_modules.py --repo /path/to/codex/current-repo --write-new
```

`--write-new` 只增加**尚不存在**的文件，若已有目标文件不同，则打印 `CONFLICT` 留给 Codex 手工三方合并；不会自动覆盖已有内容。脚本只负责复制，**不负责把组件自动插入业务页面**，这一步由 Codex 按当前仓库版本实施，且需要真实浏览器验证。

### 真实资源过审前

健康页只显示新版人物参考图，并标识“3D待审核”；模型播放功能代码、形变接口与权限审核不删除。
动作页只显示同人物外观参考 + 原动作步骤（不是该动作姿势），不出现错误的播放按钮。旧通用模型不得出现在任何可见角色槽中。
