## 文件合同

个人模型沿用 `/media-v2/` 的本地文件合同，建议 `characters/<characterId>/<assetVersion>/character.glb`。动作 GLB 沿用 `/fangkun-motion/assets/<exercise>-<gender>-<version>.glb`。均不得指向外部下载地址或旧人物。

`CharacterAsset` 的 glb 需要 `{path, sha256, bytes}`。动作条目需要 `character_sha256`、`clip_name`、`asset_version`、`rig_version`、审校证据 `docs/qa/*.json` 和审校者。六项审校是许可、人物外观、蒙皮、动作运动学、器械接触、移动端 WebGL。

摄像机限定正/侧/背/斜侧，不允许从下方窥视。中止挂载和切换角色必须销毁旧 renderer、纹理、骨骼实例与事件监听。当前动作加载器已实现这些控制，不等于未来个人模型已完成验收。

## 数据边界

`avatar-appearance.ts` 的视觉偏好继续保留；`supportedMorphs` 必须来自实际形变键，未知能力不可假装支持。不能通过缩放同一参考图冒充体重/体脂预测，不改身体实测、饮食、训练事实和正式计划。个人模型以后接入仍须与健康事实分开。

六个代表动作 ID 保持 `back-squat`, `rdl`, `bss`, `bb-row`, `bb-ohp`, `calf`。目前 0/12 已通过，不因暂停制作而改成 SKIP=PASS。

## 恢复工作时

先对新文件执行 SHA、许可、外观与网格审查；再验收权重和真实动作，再生成同角色分解帧与移动端性能证据。更新审校清单后跑三入口、离线回退和缓存撤回测试。未经用户新的集成授权不发布。本轮草稿、GLB、母版与渲染留在独立 studio 归档，不进入 production assets。
