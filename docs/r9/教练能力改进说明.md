# 方坤 R9：好教练手册接入（未测试候选）

本轮以已交付的 R8 源码为基础，参考用户上传《方坤好教练手册》v1.0 修改实际调用链。用户明确要求暂时不用测试，因此本轮未运行单元测试、回放、类型检查、构建或浏览器验收；也未调用 Gemini 或其他外部模型，未发布。R8 的通过记录不代表 R9 已通过。

## 已实现的代码改动

1. **带证据分级的教练知识。** 新增 14 个主题：RPE、间歇、跑量、睡眠、疼痛、心率、GPS、力量/RIR、跑步与力量整合、青少年、疾病回归、高温、能量不足、加速跑。每条带研究证据/机构共识/经验规则/不确定标签、手册参考文献编号、适用边界和关键问题。通用知识按主题检索进入模型请求；本地一般知识问答也接入，不能把资料里的数字当用户成绩。
2. **具体观察与竞争解释。** 单次训练复盘根据当前有效、同口径的实际分段算平均用时、平均配速、末段相对前段差及极差/均值；解释配速策略与状态/记录条件等可能原因，并说明什么后续事实会削弱它们。力量复盘保留实际组与重量，区分“完成记录”与“动作质量、剩余次数仍未知”。只在有相应事实时生成解释，不给算数题或缺数据场景硬凑因果。
3. **有决定意义的追问。** 最多三个，说明答案如何影响下一步。当前症状与睡眠、训练目的、心率口径、动作质量/RIR各有不同作用。正式记录已含RPE时不重新问数值；消息已自报RPE但未正式绑定时问口径与保存意图。已报告当前状态或末组目的时，减少同项重复追问。文字匹配不等于可靠的多轮语义识别。
4. **条件化候选。** 保留已有跑步对照候选，补充力量已记录重量的保持候选。未知原值不编剂量，未核实恢复不主动缩短休息。保持只表示暂缓调整，不代表可以照常做高强度。没有新加自动改课表或授权弹窗。
5. **建议结构审查。** 模型结构化建议需写清一个变量、原值→新值、适用条件、停止/退回条件与反馈复查。将不完整建议移除，保留已通过事实审查的正文。识别变化变量时不再仅因同时提到“配速/组数保持不变”就判多变量；原事实、引用、疼痛、密度增加等守卫继续执行。此审查仍属结构/词法规则，不是完整语义认证。
6. **共用安全动作。** 补充“差点晕倒”、胸口很紧、热环境意识异常等表述；急症先给停止与急救动作，在线输出也不能在急症后继续拼训练建议。发热/全身症状先暂停训练；明确自报未成年人申请极限测试时，要求转向有监督的技术学习。保留历史、否定及科普语境的区分，不诊断病名。
7. **解释预算。** 结构化单次教练回答的上限调到1200 token，使两种解释和条件不再挤在旧的约240 token预算中。原有调用授权与费用开关未改，未发起调用；未来接入任何模型时仍需评估延迟、费用和格式兼容性。

## 接入位置

- `src/lib/core/coach-playbook.ts`：知识条目、分级、参数、主题检索、本地知识解释、青少年边界、建议结构审查。
- `src/lib/core/coach-playbook-review.ts`：只读取有效快照与已有计算结果，构建观察、竞争解释、反证条件、关键问题和复查信息。
- `coach-reasoning.ts`：生成并展示教练复盘，推理标识更新为 FK-R9-REASONING-1；兼容旧R6/R7依赖收据，不把旧回答当训练事实。
- `coach-local-first.ts`：本地知识与训练解释入口。
- `coach-pipeline.ts`：模型无关的请求上下文、系统约束、建议审查与缺少反证时的说明补充。
- `coach-local-safety.ts`、`coach-evolution-v4-c10.ts`：统一紧急动作与健康边界。

## 对手册的取舍

- 手册 EX-01 在恢复未知时仍建议缩短恢复，与“未知则保持”冲突；未照搬其剂量。
- EX-14 的天气直接估算 WBGT 缺少必要测量条件；未建立手机温湿度到 WBGT 的伪精确换算。
- 观察性研究与“10%规则”不能变成所有人的安全线；没有新增 ACWR 决策门槛。
- GPS 的研究平均误差不等于单次测量误差范围，不把0.99 km自动改为1000 m。
- RIR估计不等于已经额外做完规范次数；没有把单组RIR或整课RPE直接转为加重许可。
- 加速跑可以与间歇主课分列，但不能从总距离/机械暴露中消失。
- 低疼痛分数不等于继续训练许可，已确诊跟腱康复模型不能推广到所有疼痛。
- 原始范例只用于阅读与提炼表达方法；运行时不加载原始好/坏答案和评分样例。模型上下文使用无个人数字的改写表达模板。本轮未打开或使用评分样例打分，未训练模型参数。
- 参考文献来自用户手册，未联网复核原文；代码和界面不会声称本轮已完成论文核验。

## 后续仍需验收
