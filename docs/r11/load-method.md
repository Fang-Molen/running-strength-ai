# R11 负荷变化提示的计算与限制

界面位置：教练 → 今日状态与专业分析 → 负荷变化提示。该面板读取本机已经保存的整课评分和时长；聊天中的自报评分必须先通过确认按钮保存，不能直接成为趋势数据。

## 输入与日期

- 每节课的负荷为 `整课 RPE × 实际整课分钟 = AU`；末组或单段评分不进入整课负荷。当前计算器接受 1–10 的整课评分、正数且不超过 1440 分钟的整课时长。
- 原生训练从开始和结束事件取得经过时间，毫秒除以 60,000 转为分钟；导入训练的秒数除以 60。缺少有效结束记录、整课时长或评分时不计算该课。
- 按 Asia/Shanghai 日历日汇总同一运动者的训练，选择连续 28 个已经结束的日期。相同记录 ID 的相同重传只算一次；冲突副本阻止对应日期计算。
- 用户须明确确认这段日期的全部训练均已记录、整课时长包含热身与整理，且没有记录的日期确实没有训练。只有确认后的空日为 0；尚未确认的空白日是未知。此确认不会补造缺失的 RPE 或时长。
- 确认以追加记录保存，并关联逐日来源快照。记录被新增、更正、作废或删除后，受到影响日期的旧确认失效，须重新核对。更正按提交时间排序，并按查询时点过滤；无法核对提交时间的相关记录保持不完整，不把未来更正直接带入过去视图。

## 公式

先将每天的各节训练 AU 相加，记为 `L_t`。仅在 28 天都完整时计算：

```text
α_7 = 2 / (7 + 1) = 0.25
α_28 = 2 / (28 + 1)
E_7,1 = L_1
E_28,1 = L_1
E_N,t = α_N × L_t + (1 − α_N) × E_N,t−1  （t = 2…28）
比值 = E_7,28 / E_28,28
```

种子是窗口第一天实际已知的 AU，不在窗口之前填充 0。两个均值都包含最后一天，因此这是包含共同数据的描述性比值。长期均值为 0 时显示零基线说明，不返回无穷大或虚构比值。界面将均值显示为一位小数，比值显示为两位小数；内部递推保留数值精度。

例如，前 27 天明确确认无训练、最后一天保存整课 RPE 6 和 50 分钟，则日负荷为 300 AU，短期均值为 75.0 AU，长期均值约 20.7 AU，比值约 3.63。这个数值没有对应的安全/危险分区，也不意味着可加量、恢复正常或某个受伤概率。

## 尚未验证的范围

28 天窗口和首日初始化是明确的实现选择，不等于无限历史或充分预热后的稳定估计。用户的完整性确认也可能有遗漏。没有使用真实长期队列校准个人阈值、伤病关联或训练效果，未实现 TRIMP。当前测试验证公式、缺失与零分母、来源归属、重复/冲突及更正后的失效行为；它们不能证明生理预测有效性。
