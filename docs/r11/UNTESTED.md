# R11 未验证项与限制

本文件区分真实本地验收与尚未完成的外部验证。具体已执行命令、退出码和数量以根目录 `status-r11.json` 与 `evidence/` 完整日志为准。

- **外部未见题盲测未执行。** 没有读取、生成或修改验收方的封存题。开发集指标不能当作独立临床有效性、安全性或泛化能力认证；外部安全否决率、总分中位数、D/A 分数均未知。
- **真实模型调用为 0。** 未调用 Gemini、xAI、OpenAI 或其他模型；有害输出替换、诊断过滤、JSON 校验和一次重试只在模拟输出下验证。实际供应商接口、网络异常表现、真实回答质量和费用没有实测。未改变现有供应商选择。
- **未部署、未发布。** 构建与浏览器验证只针对本地开发和生产预览；没有验证公网部署、真实账号、跨设备同步或生产数据库迁移。
- **浏览器使用合成数据与 Chromium 模拟视口。** 桌面和 390×844 的实际页面操作不等同于 iOS Safari、实体安卓、各种浏览器版本、离线升级及长期存储兼容性测试。
- **约 30 万字原资料未找到。** 只报告当前可读取的知识条目与汉字数量，不能将字节数、代码大小、历史快照或测试语料当作知识库规模。原手册及引用未逐篇独立复核。
- **中文语义检查仍有边界。** 症状维度、语境、诊断名和标识信息处理是确定性规则，不能保证识别所有方言、错字、省略、复杂否定或隐含身份。自建语料由开发者编写，检索样本与领域概念的设计存在关联，不是独立盲测。
- **下一课候选不自动改课表，观察幅度没有经过个体效果验证。** 仅在记录与当前状态都满足明确前提时，提供“恢复时长增加 30 秒”这一单变量观察选项；阈值和幅度是产品启发式，不能当作科学切点或经验证的个人处方。次数、距离和目标配速保持不变；证据不足、来源被撤销或存在阻断条件时 HOLD，相同前后值表示维持参数。尚未验证真实用户的长期效果。
- **EWMA ACWR 只描述已保存负荷。** 7/28 日均值在所选 28 天窗口内初始化，二者都包含最后一天，并非基于全部历史的稳态估计。记录完整性来自用户明确确认，不是设备或医生认证；缺失记录不能推定无训练。没有校准受伤风险、个人安全阈值或训练效果，也不据比值自动改课表。详见 `load-method.md`。
- **promptfoo 验证的是本地确定性行为，没有 LLM 裁判。** dev/adversarial 的 50 条合成输入调用真实应用函数，不能代替真实模型回答质量或外部封存题。关闭遥测后依赖仍尝试发送已知 opt-out 事件，该事件已在连接前阻断并保留审计；本地 Unix IPC 阻断单独计数。不能把“实际外部请求为 0”解释为“没有任何连接尝试”。
- **开源清单的后续扩展未全部实施。** 向量检索、TRIMP、FIT/GPX/TCX Worker、多品牌实机文件与独立模型裁判尚未接入，详见 `resource-adoption.md`。本轮不将这些列为验收通过。

因此，本地验收通过也不等于已经满足 R11 的外部盲测放行门槛。是否进入陪同内测仍需由验收方运行独立题集评估。
