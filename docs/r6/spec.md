# R6 个体周期教练规格
在实时 master c8053c8 的 R5 上落实四项：来源可靠的个人画像；比赛目标/滚动周期规划；实际执行反馈修订；可复放的对照案例验收。用户授权集中实施并最后统一验证，不重复审批设计。

复用90天分析事实、有效资料、原安全评估、日历写入锁及R5原子审计；不另建疲劳引擎，不覆盖V4、不修改实际记录、不清缓存。新周期只在独立分支经PR交付。模型没有写入权限；不调用付费模型、不部署。

周期目标使用已确认、带版本来源的独立目标合同（目标不冒充能力）。可用日期/时长/器材/限制优先现有有效资料。能力分项、保留缺失，近期实测成绩不推断全能等级或阈值。按照专项与日期生成全周期阶段图及每周课程草案；阶段分配和进阶门槛标为可配置产品策略，不能宣称生理模型。完整具体课程优先复用本人有实际执行证据的结构；无可靠课程/剂量仍提供目的和条件草案，关键缺项保持null，最多两个追问。

仅最近可执行一周可确认；更远周是条件规划，到期按最新事实重算。无疼痛不代表恢复已证实；疼痛/限制优先。单一设备指标不能放行。进阶仅在用户明确允许提出、同协议重复实际支持且没有恢复担忧时提出单变量候选；默认维持，不补漏练、不静默加量。每课明确目的、依据、观察和撤回条件，跑力统筹、饮食仅完整性提示与训练类型联动。

记录接受/拒绝/执行/反馈状态和支持/削弱/撤回，来源更正使旧结论失效；记录原始依赖并重新生成。确认前复核所有事实版本、目标、原计划、归属，原子回执支持恢复及重复提交保护。不能覆盖后来变更或已开始课程。跨设备不同协议分别比较；本机身份隔离不能冒充云端同步。

提示词skill已安装并保存（wshobson/agents prompt-engineering-patterns），采用固定合同、相关少样本、明确事实与目标/假设边界、限定输出结构及版本化回放。禁止模型伪造事实/审批/生理诊断；回答仍1000字。

验收包含专项/经验差异、工作日变化、漏练、临赛、疼痛设备冲突、器材缺失、重复实际/进阶、目标移动、更正/撤销/跨账号/陈旧确认、未知资料、混合课、饮食不完整。工程验收和专业评估分开；不声称所有能力已专业验证。
