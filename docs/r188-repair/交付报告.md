# 方坤 R188 本地修复交付报告

本轮在 R185 最新交付源码的独立副本上修复。R1—R7 审核总包采用较旧的 R184 基线，因此只移入清单中的 12 个增量文件，未使用其 `source/` 覆盖 R185。回退点为 `r185-before-r188.zip`，SHA-256 为 `4a7af94aae8b64793b1fd2b9504cdd8b2f53a4a3ca351f8fa32f11fb34c28c99`。

## 已实现的范围

- 下一课没有已批准课程时，给出“休息”的具体、可撤回建议及停止条件。已有批准课程的转述保留来源，候选改动先交用户确认；医学限制优先，建议不会写入正式计划。
- 保留 R185 逐组数值复盘、周期观察和量化适配；处理多轮年龄、闭经、骨点压痛、急症与已就医后的运动许可边界。
- 将 P7 建议记录接到教练显示入口，使用既有 `appendJournal` 保存 LIVE 决策。历史导入与 LIVE 记录保持区分，没有数值预测的建议不计入预测准确率。
- 保存复盘时记录假设来源，更正事件直接核对来源版本。同源相关字段更正使旧解释失效，无关字段不撤回；无法确认来源关联时保留 `REVIEW_REQUIRED`。
- P7 判断和事件持久化，校准按运动员、指标、单位、协议分组，未来观察不得冒充已发生结果；新增知识保持候选状态。
- 实现可选 IndexedDB 镜像迁移及回退。逐字复制现有本地值并核对一致性，保留同步 localStorage 副本；回退切换存储方式，保留新写入训练，不把旧快照覆盖回来。
- 在现有设备准备合同加入数据质量闸门：异常心率、时间、距离、速度、平均/最大值冲突等保留原始值并阻断比较和自动导入，不能把数据质量条件当训练或医学阈值。最终审计另发现活动级 `elapsedSeconds < timerSeconds` 漏判，现已补入 IMPLAUSIBLE/BLOCKED，并新增对应合成用例；R188 专项33例及修复后完整domain均有实际收据。

R173 的 92 条 IMPLEMENTED、5 条 BLOCKED、35 条 NOT_APPLICABLE 分类保持原边界。候选研究阈值未升级为减量、停训或医学回归的自动规则，能力图仍没有未经核准的 0—100 分。

## 实际缺陷与修复记录

1. 设备准备只对分圈时间核对，活动总 `elapsedSeconds < timerSeconds` 仍可漏过。补入活动级 IMPLAUSIBLE/BLOCKED，并保留原输入；R188 33 个专项用例实际通过。
2. 新 P7 DFA 知识卡将非论文的品牌说明写入通用描述，触发原目录来源扫描合同。原 catalog 3 个用例实际 2 PASS / 1 FAIL。仅将描述中的 `resting Garmin HRV` 改为 `resting wearable HRV`，DOI、候选状态、数值、安全门控、原断言及 citation 豁免均未改；原 catalog 3 个和知识卡 6 个用例复测通过。修订哈希见 `source-freeze-change.json`。
3. 原本无批准课程不产出候选的行为与用户确认的 R188 决策不符，改为明确可撤回 REST。仅一处原测试按新产品契约改动，见断言说明；没有恢复未经批准的 +30 秒休息处方或降低医学限制。

仍未解决的是执行环境的子进程 stdio/IPC 与本地端口权限限制。4 个 npm 文件组失败为 `brand-check.test.mjs`、`check-auth-invariant.test.mjs`、`with-app-env.test.mjs`、`write-atomic.test.mjs`，均保留实际日志；浏览器启动失败也保留为真实结果。尚不能将这些失败归为已经修复的软件缺陷或声称整体 PASS。

## 尚未具备或未验证的内容

- 新提供的 Garmin 报告是字段映射与模拟验证规格，引用的是旧 R184 基线。它没有提供可直接核对的导出 JSON/ZIP 规范样例、解析器源码或真实 FIT 文件。当前设备质量闸门已补入，但 FIT/TCX/GPX 解码、账号接入、全量跑步动态/力量/身体指标映射未完成。
- 原周期性数据包只有 CSV。FIT session/lap/record、原始活动去重、确认训练课结构、设备协议与运动员身份的完整真实数据验收继续保持 BLOCKED/SKIP，不能把活动条数当课次数。
- IndexedDB 采用兼容镜像方式，尚未证明取消 localStorage 副本后可以独立恢复所有历史。浏览器持久化授权与操作系统清理行为不能由桌面 Chromium 结果保证。
- 封存盲测、真实 Garmin 新格式接入、外部模型、远程数据库和部署均不包含在本轮通过范围。
