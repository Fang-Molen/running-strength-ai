二、输入/输出约定

values 为命名事实，series 为有序原始观察。每项带运动员 ID、原值、单位、ACTUAL/SELF_REPORT/PLAN/ESTIMATE、事件时间、记录时间、来源 ID、修订版本及协议。时间须为含时区的 ISO 时间；asOf 由调用方提供，不读系统时钟。

PLAN 仅用于明确的计划目标、时间参考或声明的比较区间，不能作为实际量或实际 RPE。ESTIMATE 仅在能量可用性与同版本能力模型变化中允许，并保留估算标记；其他“实际”入口拒绝估计值。估算型输出仍明确标记，不能代替实测阈值。

完整窗口需 startDay/endDay/complete 和来源回执。每日 EWMA 需完整连续日；明确休息日为 0，未确认日为 UNKNOWN，不填零。周对比需相邻完整周且口径一致。历史比较需要一致协议，不能将手计、电计、不同距离等自动换算。

conditions 是事实适配层确认的前提，并须带 conditionSourceIds；不是本函数自动推断的事实，也不是对用户开放的绕过安全许可开关。尤其 CLINICAL_PERMISSION 只能从原有临床许可门控传入，本函数绝不授予该许可。

分段需完整结构标识和序号，一次调用只允许同一轮。ALL_SEGMENTS_COMPLETED 应由原计划槽位与实际记录对照确认；本函数不能仅从传入的若干秒数知道是否漏传最后一段。原休息字段与整个训练树继续由 Training Fact Layer 保存，不迁移至数值数组。

返回中的 sourceRefs 保留来源版本；validSamples 为被读取的不同有效输入记录 ID 数，不等同于已完成训练次数。基线样本数等另列 metrics。READY_MISSING 的有效数特指当前问题已知字段数，覆盖率不是能力或医学评分。缺少 revision 会给出限制，不虚构版本。

AVAILABLE 仅表示在声明前提下有计算结果，仍可能带部分缺失，如 Hooper 某项无历史基线。UNAVAILABLE 时 value=null，missing 给原因。某些已读原始或中间信息可能保留，消费者必须先检查 status，不能当作完整可用结果。

使用规则：只从当前有效更正投影取值，保留全部源事实与旧修订。调用方负责去重、真实来源认证、个人基线资格、完整任务分类、测量误差与临床许可；同字符串 protocol 并非科学可比性证明。任何计算输出都不能直接调用计划写入器或改变长期能力评分。
