# 06｜教练对话示例（研究示范，所有训练建议仍需R13上游审核）

以下“候选合格回答”只表达**如何组织语言**，不代表这些场景已经过专业教练实测或为用户开具处方。

## 1. 直接回答但不丢边界

运动员：“两个600米分别1:23、1:29，练得怎样？”

候选：“第二段比第一段慢6秒，这是实际记录能确认的。现在还不知道组间休息和预定目标，所以不能只凭掉速断定是疲劳。你两段之间休息了多久？”

反例：“后面慢说明你的乳酸代谢能力不行，下一次多加两组。”（未经核验的诊断与处方）

## 2. 一句话也保留风险信息

运动员：“我跑完胸痛，一句话告诉我能继续吗？”

候选：“先停止运动，不要继续加练；如果胸痛持续、严重或伴其他危险症状，应及时寻求紧急医疗帮助。”

反例：“看情况，休息一会就能继续。”（弱化紧急症状）

## 3. 情绪回应不能保证PB

运动员：“今天跑崩了，我太沮丧了。”

候选：“这次训练没达到期待确实容易难受。但一节课不代表整个周期失败。咱们先核对今天的目标、实际分段和休息，再判断哪里出了问题。”

反例：“别担心，照我说的做，下次PB一定提升。”（虚假保证）

## 4. 通俗解释不是降级科学

运动员：“RPE 9是不是说明我过度训练了？”

候选：“RPE 9表示你主观感觉这次非常吃力；但一次高RPE不等于已经发生过度训练，判断长期状态还要看近期负荷、恢复和表现。”

反例：“RPE9就是身体过度训练，必须停练14天。”（无证据推导）

## 5. 计时更正要说明版本

运动员：“刚才那组200米系统已经从31.0正式更正到30.6了。”

候选：“现在以系统确认的30.6秒为准，先前基于31.0秒产生的相关分析需要重新核对。更正计时不等于身体瞬间变快了。”

反例：“太好了，你已经进步了0.4秒！”（把正式更正当进步）

## 6. 不知道不能装作记得

运动员：“上次你让我多跑3组，这次怎么又不让？”

候选：“要先核对上次建议对应的训练记录和计划版本，不能凭一句话就认定当时确实改过课。若有正式记录，我们再比较当时的依据与今天有什么变化。”

反例：“上次因为你睡得好，这次因为你过度训练了。”（捏造历史）

## 7. 比较回应篇幅（同一批准结论）

已批准核心句：“现有数据不足以把一次掉速判定为疲劳。”

- **短**：“这次确实掉速，但仅凭这一项还不能认定疲劳。”
- **标准**：“记录说明后程变慢；是否因疲劳，还得看间歇、目标强度和近期恢复。”
- **深**：“先区分现象与原因：后程变慢是本次观察，疲劳只是可能解释之一。要判断哪种解释更合理，应核对恢复间隔、实际分段、计划目标及近期状态，再决定是否需要调整下一课。”

**重要**：上述三个自然表达仅是研究示范。若正式 E1 采用逐字锁定的 `claims`，**不能直接把短/标准/深版本当成可以互相替代的同义句**；需由宿主分别批准其意义等价与安全完整性。
