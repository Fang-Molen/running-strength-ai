# 01｜教练沟通与表达研究合同（E1）

## 边界

- 本研究组：研究和提供沟通表达策略、参考合同、测试题库、评分标准、盲评程序和结果分析。
- 逻辑/专业教练研究组：负责训练事实正确性、证据解释、训练候选选择、长期决策和安全专业审核。
- Codex：负责以最新真实仓库为基线，审查后最小差异接入、测试与回滚。
- 用户：批准合入/模型数据调用/是否发送或修改计划。本包**不构成任何上述批准**。

## 六项独立能力

1. **自然交流**：直接回答任务，不过度客套、不复述全部历史、不自称是真人教练、不造热情；可承接情绪但不改变事实。
2. **复杂问题通俗解释**：从用户关心的结论开始；必要时按“意义→证据→限制→行动/缺口”展开，训练术语首次解释，但不得“讲简单”讲错。
3. **长短自适应**：短答优先留下关键结论、关键风险和必要不确定性；深答增加经审批的解释与上下文；**安全话术和核心结论永不因篇幅压缩而省略**。
4. **情绪理解与支持**：用户明确焦虑、失望、兴奋或生气时简短回应；不诊断心理状态、不过度安慰、不许诺PB提升、不情绪绑架。
5. **必要追问**：只有缺少决策关键变量且事实不足时才问；先答已知部分、一次一个最高优先级问题、同一问题不重复追；急性安全情境先安全分流。
6. **跨轮一致性**：继承宿主验证过的来源ID、身份、轮次和时间点。正式更正后承认历史结论失效；聊天口头纠正未入库，不准假称数据库已更改；不伪造记忆。

## 技术原则

**Truth → Approval → Expression → Guard → Host permission → Delivery（当前R13不交付）**。

- 事实层为只读，表达层只处理宿主许可的语义内容。
- 必要事实的句子由宿主提供，原文不可变，带可追溯来源；承认“不知道”不因润色变成“基本确定”。
- 譬喻、概念定义、术语解释若带训练知识，必须是上游批准的 gloss；不能在表达层让模型从无到有推导新的训练强度/结论。
- 不是每个对话都必须“事实→两种解释→训练方案”，对纯计算题、情绪交谈或风险转诊应按意图回答。
- 训练中的运动医学风险、未知恢复状态和计划变更授权属于硬门槛，无法被高语言评分冲抵。

## 主要研究假设（待真实模型检验）

- H1：受约束的表达增强会在同案、同事实条件下提高普通用户对训练解释的清晰度与可执行性评分。
- H2：由宿主批准的术语释义和必要追问能减少误解与冗余问题，但不会降低专业评估准确性。
- H3：跨轮来源版本显性约束能降低“刚更正却沿用旧事实”的沟通错误。

可证伪条件：任何明显专业失真/安全退化直接否定“可交付”；无统计显著用户收益则不主张表达增强有效；成本与延迟过大则需要调整设计。
