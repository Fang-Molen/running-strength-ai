# 05｜公开沟通研究与本项目的借鉴边界

本项目不是照搬医疗对话：运动教练应受专业事实、训练安全、授权与上下文约束。下列研究**用于提出设计假设**，不能充当方坤当前训练效果的证据。

1. **CDC：健康信息应准确、可接近、可行动（accurate, accessible, actionable）**。本项目落实为两组独立评价：专业教练判断准确，普通用户判断清楚/有用，任何自然度提升不能代替准确性。原文：https://www.cdc.gov/health-literacy/php/develop-materials/develop-test-materials.html （CDC, 2024-10-16）。
2. **AHRQ：Teach-Back** 用自己的话复述要做什么，检验是否真正理解，而不是问“你听懂了吗”。在本项目可用于复杂高风险解释的*选择性*理解验证以及普通用户盲评；不能把每轮训练对话变成考试。原文：https://www.ahrq.gov/health-literacy/improve/precautions/tool5.html （2024 第3版）。
3. **动机式访谈（MI）OARS：开放式提问、肯定、反映、总结**在医疗康复沟通中有理论与应用背景；用于构建有限的情绪承接和主动追问策略。不能由此推出“更多追问/更多安慰一定更好”，更不能让 AI 伪装成治疗师。来源：Schechter & Wegener, *Motivational Interviewing Communication Skills*, Oxford University Press, 2024, DOI:10.1093/oso/9780197748268.003.0004，https://academic.oup.com/book/55919/chapter-abstract/439344885。
4. **CDC Plain Language 指南**强调受众、核心信息优先、常见用词、语义分块；本项目允许宿主批准的通俗释义，但不许为了顺口弱化训练事实、风险和因果边界。指南：https://www.cdc.gov/health-literacy/php/develop-materials/plain-language.html。

**待验证而非已证明**：使用这些沟通方法是否使方坤的用户评分提升，以及是否影响专业忠实性，必须经过本包 `03-盲测与验收.md` 规定的真实 R13 同案 A/B 才能得出结论。
