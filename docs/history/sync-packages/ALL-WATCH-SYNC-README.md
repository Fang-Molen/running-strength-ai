# 方坤 v89.10.6 — 现有手表同步优化补全

本包在上次 `fangkun-v89.10.6-sync-optimized.zip` 完整源码上继续修改，包含已有 UI、时间显示、健康趋势和佳明优化。当前账号直连仍是佳明和高驰；其他品牌沿用已有文件导入入口。

## 本次修改

1. **高驰读取提速**：健康接口完成初始化后最多并行读取两个指标，继续按原顺序解析和合并。相同状态、活动或分圈的并发读取共享请求；状态短缓存为5秒，手动活动读取保留近28天，自动检查保留近7天和10分钟间隔。
2. **读取状态连续显示**：自动读取也显示“读取中”；离开页面再回来继续观察同一个任务和结果。活动保持核对、勾选、保存的原流程。分圈等待时禁止重复提交，当前页面重复查看复用结果。
3. **失败与授权处理**：请求有明确超时，失败后释放等待状态；限流后停止派发剩余健康请求，已完成的有效指标保留，未读取项目写入现有问题列表。授权过期不会被较早的状态响应覆盖。
4. **断开和切换用户保护**：断开期间暂停新读取及重新授权入口；共享会话撤销在切换运动员后仍等待完成。迟到的活动、健康、分圈响应不能写入新用户的预览或缓存。旧健康响应不能覆盖更新的记录。
5. **健康结果与文件预览**：部分指标缺失时保留已知值和原恢复数据时间；本机缓存写入失败时仍展示刚收到的有效结果；首次授权失败会显示准确提示。各品牌共用的 CSV 预览以最后一次选择为准，清除后旧读取结果不会重新出现。

## 数据与界面保持

沿用当前设计，不改字体、颜色、页面布局、健康趋势的日期导航和已有曲线。跑步/力量分类、导入确认、来源标记、去重、方坤既有计划关联与分圈小数秒显示继续使用原有逻辑。

本轮只修改5个现有源码文件，新增4个实现/测试文件。其他1716个已有源码和资源文件逐字节保持一致。上轮的6份交付说明按历史记录保留；本轮内容以本说明和 `ALL-WATCH-SYNC-VERIFICATION.json` 为准。
