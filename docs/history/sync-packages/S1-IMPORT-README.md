# S1 统一同步与导入修复版

基于本次上传的 `fangkun-s1-精简源码.zip`（包内版本 v89.10.9）。这是完整源码包，解压后仍为 `fangkun-v89.10.9/`；保留原有 1,790 个文件，未删除原文件。

## 本次完成

- **沿用现有界面与统一窗口。** 账号连接、文件导入仍在同一个设备中心；原有健康趋势日期回看、训练时长显示和平台同步入口继续保留。
- **状态明确勾选后保存。** 缺失、未佩戴、冲突、撤回记录默认不选；保存数量与实际保存内容一致。已选读数保留自身的原始证据历史。超过 20 条状态或 200 条活动可继续展开核对。
- **人工更正同步到健康显示。** 保留原值，追加人工更正修订，健康快照显示最新确认值及人工更正标识。连续更正、日期前移/后移、重导入、Apple 睡眠聚合均有针对性回归。
- **无效更正及时恢复。** 输入被拒绝时，输入框恢复到更正前的值并显示原因，避免界面数字和实际保存值不一致。
- **切换账号后废弃旧解析任务。** 包括快速从 A 切到 B 再回 A；旧文件读取和识别结果不会进入新账号的预览或保存。
- **原始证据批量保存减少重复扫描。** 每个批次建立一次已有证据索引，保留去重、归属检查、冲突和保存失败保护。
- **授权回到同一窗口。** 授权回调与快捷导入参数同时出现时优先打开统一账号窗口；初始化重复执行也不会再多弹健康导入窗口。

## 提速验证

使用合成数据统计原始证据存储读取次数：

| 场景 | 修复前 | 修复后 | 写入结果 |
| --- | ---: | ---: | --- |
| 首次保存 20 条事实 | 210 次 | 20 次 | 保存 20 条 |
| 再次保存同一批 20 条 | 400 次 | 20 次 | 0 次新增写入 |

该结果针对原始证据保存入口的重复读取；底层日志追加仍有存储枚举和读回确认，不据此宣称网络传输或整个同步链路提速相同比例。
