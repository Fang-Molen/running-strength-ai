## 重要限制
- 只识别明确陈述的5000米 PB，其他项目未泛化；这是小范围、可复现的能力，不是完整自然语言理解。
- 状态仅通过函数输入输出传递；未写入 App localStorage，也未连入真实 AthleteState 或训练事件流。
- PB 属于用户自述，未独立核验。Riegel 1.06 仅输出历史等效换算，不能作为当前成绩预测。
- 不能凭文本识别证明医疗安全，当前安全识别仍依赖正则；临床风险场景需更广泛的负例测试。
- 没有执行全量 TypeScript 检查、完整 App 构建或端到端浏览器测试。
- 没有使用 GPT API 或外部模型作为运行时推理引擎；代码由 ChatGPT 协助编写。

## 下一阶段验收门槛
1. 与训练事实和 AthleteState 做只读接入；不猜测缺失分段。
2. 建立用户确认的纠错/覆盖语义和事件审计，禁止静默改写 PB。
3. 真实训练事件跨天回放、缺失信息处理、反事实安全评估。
4. 130题原文独立回归，加入反例和对抗样本；不能把脚本通过率称为教练水平。
