# FRAME-05 · 统一导入中心第一批：CSV 本地批量预览

状态：PARTIAL IMPLEMENTATION / NOT FINAL PASS（2026-10-10）

## 本轮实现
- 在既有「身体 → 智能设备接入指南」增加 CSV 批量文件只读预览，支持一次展示最多20行并显示实际行数、列名与列数。
- 新增纯函数 `src/lib/ui/device-csv-preview.ts`，支持 BOM、CRLF、CSV 引号与转义逗号，检测列数不一致和异常引号。
- 预览限制文件为 `.csv` 且不超过2MB；不上传、不写入 localStorage、不建立训练记录、不影响原有饮食、热量、身体数据。
- 新增测试 `device-csv-preview.test.ts`：3/3 PASS。
