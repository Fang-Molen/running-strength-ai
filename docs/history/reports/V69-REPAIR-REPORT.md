# 方坤 v69 基础修复与接续说明

基线：用户上传的 fangkun-v68-source.zip。日期：2026-10-17。
本次为源码修复；没有部署到 molen-fangkun.pages.dev，没有访问手机里的训练数据。

## 两部分问题的原因

1. 我的形象与体型目标：v68 在 home-dashboard.tsx 明确关闭 ShapeSim3D，Figure 只返回同一张立绘，不读取体重/体脂形变参数。因此 56kg 和 60kg 人物一样不是刷新故障。旧目标选择器还写死 54–66kg，体脂为空却显示已定位滑杆，且大量重复立绘把保存操作推到底部。
2. 动作详情与肌群：MuscleCard 直接输出 muscleMapSVG，所以大块几何人体就是该版实际实现。DemoBlock 把插画和动画上下叠放；动画与独立肌群入口复用 human.glb。该包只有通用男性表面网格及 regions.png 分区贴图，没有设计稿同角色的精细人物、女性配套网格或独立解剖肌肉网格。图片性别选择没有驱动动画人物。
3. 模型细节不足属于资源缺失。限制镜头、换材质、增加颜色或 CSS 无法使区域模型变成精细解剖模型。

## 本次已经修改

- 健康页：收紧人物卡，目标入口只显示体重数字差值；详情仅保留一个标准角色，没有复制第二张图充当体型变化。
- 目标：输入与加减、快捷值，体脂率选填并可清除。复用带键盘适配的固定头尾弹窗，保存成功有状态，失败保留输入并回滚目标值。只使用原来的目标/个人资料键，不写实测体重或体成分记录。
- 动作详情：同一个演示区域切换插画/动画，通用男性动画和缺少的女性动画明确区分；动作步骤、参数和休息保留。
- 目标肌群：接入已有真正的 WebGL 3D 区域点选能力，移除本详情中的几何拼块肌群图。主要/辅助/选中颜色分开；点选后仍保留其它肌群角色。细分键与组键均可匹配，修复比目鱼肌等高亮遗漏。
- 交互：前后左右及足部/小腿聚焦；所有相关查看器采用同一镜头限制。切换预设先清空惯性与旧约束；上限为平视，不允许从下往上翻转，缩放和水平旋转受限。赤脚展示按可见脚底落地，而非隐藏鞋底。
- 遮挡：未标注的裆部覆盖区域保持不透明；失败备用入口改用肌群名称列表，不显示旧的裸露解剖插画。但尚未制作真实服装覆盖网格，也未完成所有姿势/角度的真机验收。
- 稳定性：共用模型加载请求、取消时清理、缓存 v69；新增的公共模块加入离线资源列表。
- 构建：修复原包两处静态构建兼容问题，保留平台品牌、中间件和安装教程。构建必须退出码为 0，不再要求忽略 SSR 错误。

## 包的使用

source/ 是以 v68 为基线的完整 v69 源码；patch/ 只包含修改或新增的文件。
PATCH-MANIFEST.json 记录每个文件修改前/后的 SHA256。若还有比 v68 更新的开发副本，应逐项合并差异，不直接覆盖新改动。
validation/ 是本次实际检查日志与结果，不含浏览器截图。
使用原来的 Cloudflare Pages 项目 molen-fangkun 和域名。源码包不包含手机里的 IndexedDB/localStorage 记录，也不包含发布凭据或模型 API Key。
