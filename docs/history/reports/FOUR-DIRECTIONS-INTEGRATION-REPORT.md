# 四方向教练推理升级（独立源码候选）

新增 `src/lib/core/coach-four-directions.ts` 与 10 项测试：
1. 多假设疲劳解释，区分睡眠、RPE、主观恢复、CMJ与局部疼痛；不诊断中枢/外周疲劳。
2. 个人CMJ基线：仅使用当前日期前至少3次历史观测的中位数，缺失明确UNKNOWN；7%变化只是复核提示，非临床阈值。
3. 训练处方审查：对下一节训练目的及强度输出只读候选，疼痛与高强度冲突先走安全审查；不自动更改课表。
4. 预测-验证-纠错：对有配对实际成绩的预测计算有符号误差、绝对误差及百分比；无成绩则UNKNOWN。
