# BUILD 31 - 方坤能力画像与表达风格

## 能力画像（基于源码审阅，不等于独立能力评估）
- 本地免费：规则式训练、营养、恢复与风险问答；可读取绑定的训练事实、部分饮食记录；基本多轮上下文；前台事件提示。
- 训练决策：存在决策/安全逻辑与提案候选；冻结权限保持，聊天不能自行修改正式周期课表。
- 线上大模型：主动申请路径存在，但赠送额度、审批、稳定在线知识服务未完成。
- 不具备：可靠自然语言泛化、医学诊断、完整个体化营养处方、关闭PWA后的持续后台监测、已验收的自动改计划闭环。

## 新增
- 专业均衡、严格督导、温柔支持、数据分析四种用户可切换表达风格。
- 浏览器 localStorage 保存偏好；不可用时仅本次会话生效。
- 风格只附加引导句，不改原始答复、证据、医学警示、决策或训练数据。
- 默认免费本地问答、用户主动线上申请机制不变。

## 限制
- 这是可切换表达风格，并非训练了四个语言模型。
- 未安装依赖时无法声称生产构建或真机验收。
