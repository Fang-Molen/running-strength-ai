# 方坤 v71 源码交接（候选，未部署）

本次基线是用户上传的 `fangkun-v69-source.zip`，已包含前一份未上线v70候选的精细肌肉图谱与扩展动作目录。修改位于独立副本，没有操作用户手机、线上存储或生产部署。最终包的差异清单以实际v69压缩包为准，不能假定线上已装v70。

## 本次入口与操作

1. 首页/计划页添加训练：先确认日期，选择跑步或力量，再编辑训练内容和名称。力量内容上方是“人体肌肉3D · 点肌肉选动作”。在图谱中连续选择动作后返回同一草稿，填写各动作参数后保存。
2. 第二页“计划”：顶部两个并排入口“跑步运动 / 力量训练”。力量区展示肌肉3D、动作库、添加训练、已排训练与原课程库；周期和高级工具折叠保留。
3. 首页计时：按当前选中日期读取已确认的日程课程，进入该课的逐组或分段执行。存在唯一进行中课次时先恢复它，不再让用户从“推进/后链/稳定”等无关模板重新选。
4. 同一模板的不同日程有独立课次标识。返回保留原课次；再次开始已结束课程会明确另建课次。训练进行中不改写原计划快照。
5. 完成记录由实际逐组/分段结果投影回原日程，不用预计分钟冒充实际时间。混合课需要两部分都有闭合记录；部分完成不会记为整课完成；用户手填的实际记录不被自动覆盖。
6. “我的形象”用一张原人物立绘和当前/目标数字。目标保存不覆盖实测体重或体脂；不以两张相同图片或缩放假装体型模拟。

## 资源实际状态

- 精细肌肉图谱：`public/demo3d/anatomy/ecorche.meshopt.glb`，包含634个结构、362个独立命名肌肉网格；约98万三角形。支持肌肉点选、分层、固定站姿、正/侧/背预设、足部/小腿聚焦与受限镜头。模型来源、修改和CC BY-SA 4.0义务见同目录授权文件，不能删去。
- 动作示范人物：仍是原项目 `human.glb`。本次只调整黑色头发/眉毛、深色运动服、材质粗糙度和纹理细节；没有改脸型、网格、骨骼和动作轨迹。它不是原设计图那个定制人物的重建成果。
- 原设计人物：已核对回收的原包，所谓原 `human.glb` 与现用文件字节完全相同。未找到与原人物立绘匹配的绑定模型、Blender工程或形变目标。下一步需要另行制作匹配人物的骨骼模型、服装和动画，并经过多视角验收。
- 个人3D与56kg→60kg体型：未完成。准确外观不能仅由体重/体脂两个数字确定，需要独立角色资源、校准后的形变与适用范围，不将当前通用动作人物冒充个人模型。
- 扩展目录：876条英文文字动作候选，保留来源/许可；无图片、无动画的条目不补造媒体。肌肉映射与动作要领仍需逐条专业审校，颜色不代表实测肌电激活或疲劳。
