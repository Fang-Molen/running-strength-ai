# 能力与数据缺口清单

本轮不把工程通过率换算为教练分数。以下逐项区分读取缺口、尚未采集、实现缺失和未验证环境。

| 用户问题 | 已有与缺失资料/覆盖 | 原因类别与现阶段可确认部分 | 最小补充/验证、候选风险与责任模块 |
|---|---|---|---|
| 这节跑得怎样，明天怎么练？ | 已选A的分段、休息、整课RPE、近期反馈及日历；未必有测试协议、局部功能或完整48/72小时反馈 | 数据不足；现有数值可复算，不能认定掉速原因或保证恢复 | 只补当前决策需要的目的、疼痛/功能；保留/调整/暂缓候选须确认。online-context、recovery-assessment，P0 |
| 去年有没有类似训练？ | 本机保留的一年及更早记录可按需读取；被旧版数量上限淘汰或未导入的资料无法凭空恢复 | 已修读取范围；数据不存在与读取失败分别报告。旧训练不计近期肌群负荷 | 若缺原资料则从原备份或设备确认导入；跨设备协议分开。analysis-host、history，P1 |
| 跑步熟练但力量新手该怎么安排？ | 独立字段及已有力量档案来源、时间；专项PB、真实力量测试仍按原记录读取 | 分项经验已接入，经验不是实测能力 | 仅关键课缺少该项经验时追问；动作熟悉度/真实负重需专业复核。cycle/portrait、planner，P1 |
| 没有LT2能否给双阈值精确配速？ | 有历史跑课及模型比较；没有有效LT2/乳酸协议时缺标定 | 数据不足，不能编造LT2配速；可以条件性比较训练组织 | 补有效测试或使用已核验的熟悉课程剂量，不自动加量。training-models，P0 |
| 正常HRV能否解除腘绳肌疼痛限制？ | HRV与疼痛/功能独立保留；医学判断未由程序完成 | 不允许由HRV或恢复曲线解除限制；能解释证据冲突 | 急性风险按现有安全流程；局部功能和医疗复核由合适专业人员处理。recovery-assessment，P0 |
| 模型为什么忽略本机分析？ | 本轮实际HTTP/SQL假服务已收到代码计算、来源版本、有限对话；长资料受48KiB/4800字节提示预算裁剪 | 当前入口接线已修；裁剪仍存在；客户端分析仍是申报，不是服务端独立设备验真 | 保留所选结构和计算优先级，显式列未发送数量；真实DeepSeek能力需另行批准测试。online-handoff、controller，P0 |
| 更正一圈后其他页更新了吗？ | 合成贯通已核对旧解释撤回、旧候选失效、健康采用新分段，训练原记录/餐食未覆盖 | 主要逐段/逐组路径已修；模糊反馈更正和首次来源捕获失败的持久补审仍有缺口 | 精确绑定原条目和字段，模糊值保留未知；补审失败保持过期状态，不恢复旧结论。coach-import-evidence、training-correction，P0 |
| 恢复备份是不是已经全部安全？ | 已有隔离候选、读回检查与部分写入屏障；旧标签和所有旧写入口未完成统一隔离 | 实现缺失；备份暂存不等于正式恢复 | 补跨标签生命周期与失败恢复后再开放；不得覆盖正式历史。backup restore / storage，P0 |
| 能自动调整饮食和训练目标吗？ | 已记录食物与部分份量、训练日历；全天餐次完整性和总消耗常未知 | 可解释已记摄入及候选，不能把未记录算零或把活动消耗当全天消耗 | 补必要份量/餐次而非重复整份档案；长期控重与营养特殊情况待专业评估。nutrition、R5，P1 |
| 能预测比赛成绩或证明进步原因吗？ | 已有可比历史与反馈反证框架；无本轮真实长期/时间外评估 | 知识/规则和专业验证不足；一次训练不能证明因果 | 保留竞争解释，记录24/48/72小时反馈；独立教练/运动专业评审。adaptive-review、assessment，P1 |
| 手机键盘、iPhone/iPad和真实多人联网可用吗？ | 合成回放、权限/快照/账本代码；真实账号、生产PostgreSQL、Safari真机、DeepSeek本轮未测 | 环境/外部验证不足；不得宣称联网恢复 | 桌面/模拟手机浏览器与真机分开；真实部署/付费测试需另行授权。前端、coach-http，P0 |

历史费用：其他环境仍为 UNKNOWN_PENDING_RECONCILIATION。假服务的合成价格不代表真实价格或历史费用为零。
