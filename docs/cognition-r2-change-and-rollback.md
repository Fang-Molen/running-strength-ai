# 方坤 AI Brain 第二轮：变更与回退

本轮基于已交付第一轮 `7b28b81d68408907ae021eb677ceaa7eea3f0e0f`，本地分支 `cognition-r2`。用户已明确允许修改原冻结模块；本轮仍保持候选隔离，没有部署、替换正式版或读写真实个人训练存储。

## 架构变更理由

| 模块 | 修改与理由 | 验证及边界 |
|---|---|---|
| storage / events | 原共享数组读改写在两个写者交错时丢记录；改为每条记录独立物理键，不依赖共享可变索引。保留旧 envelope，只读合并。 | 重现探针、两个独立适配器交错写、旧记录不变；不是浏览器双标签实测或多存储事务证明。 |
| cognition learning | 反馈使用同样独立键；revision 用于发现已可见的过期写，而不把它当锁；冲突逻辑 ID 全部保留并排除推断。 | 相同 ID 并发冲突、过期 revision、撤回/更正、预测早于实际观察、可比与反例测试。 |
| backup / trial | 独立物理键的长度超过旧80字符上限；限定允许新三类命名空间的较长键，保留其他键原限制。 | 真实导出、检查、恢复、重新读取，涵盖旧反馈、新事件、新反馈和首周选择；没有删除历史。 |
| event / feedback UI | 监听其他标签的 storage 新记录通知；监听错误不影响落盘；反馈初始 SSR 不读个人存储。 | 函数与SSR测试通过；真实跨标签通知尚未浏览器验证。 |
| first-week intake / coach UI | 新增独立自报回答日志与可编辑首周候选；当前能力、目标、实际训练分开。 | 六步依赖、不同基础与可用时间、缺失、安全、成绩纠错、候选保存与重新读取测试。 |
| runtime mjs / JSX types | JSDoc补齐类型、明确 nullable 数值、补全测试契约、修复 boolean/number 比较。 | 保留 strict / checkJs，不使用全局忽略、放宽编译配置或关闭失败测试。 |
| 旧失败的UI/PWA/品牌契约 | 修静态食品示例误命中SSR断言、通用设备标签与指南、PWA产品名称和已有尺寸图标；4项测试原依赖缺失的外部skill文档，转查仓库内真实契约文档。 | 原有断言仍运行；外部skill没有伪造或声称恢复。平台206测试通过。 |
| 测试适配器 | 54处 Map 存储模拟补 durable keys 枚举，匹配新的存储能力；coach brief写入契约承认事件新命名空间。 | 业务断言继续运行。首轮反馈备份测试原为两个缺失旧键比较，本轮改为非空数据和完整恢复比较。 |

## 数据边界

新命名空间：`fr255-event-journal-v2:`、`fr255-cognition-journal-r2:`、`fr255-coach-intake-r2:`。旧 `fr255-events-v1` 和第一轮反馈 envelope 不被新追加覆盖。计划候选和首次自报不会写成完成事实；接受候选只记录用户选择，不替换正式课表。

一条记录的落盘以一次 localStorage setItem 为边界。事件、发生实例、运行快照、训练更正等多个存储键之间仍没有整体原子事务；没有把局部修复宣称为所有并发问题已经消失。损坏日志不会被删除，但当前读投影只忽略无法解析条目；尚缺显式损坏诊断界面。日志保留所有条目，尚未实现大规模压测和安全压缩。

## 回退

1. 回退前保留R2完整源码、补丁、source manifest及R2导出的完整本机备份。第一轮代码不会识别新日志键，旧代码下看不见新记录，不代表可以删除它们。
2. 代码可在独立目录从随包 Git bundle 的 `cognition-r2` 分支取出，另建 worktree 指向 `cognition-r1-delivered`；或在无其他改动的候选副本逆向应用随包 `changes-vs-r1.patch`。不要对正式工作目录使用 reset --hard。
3. 保留所有新命名空间，不作逆向数组迁移，不清空localStorage，不覆盖任何个人备份。需要恢复R2记录可重新运行R2读取器或将原始备份转交人工核对。
4. 第一轮回退代码有已知并发及类型/测试问题；回退是恢复候选基线，不是发布批准。正式版始终未被本轮操作覆盖。

## 开发与复现入口

完整源码含 package-lock、原迁移文件、public资源与平台配置。`README_ROUND2.md` 列出命令，实际结果保存在 `evidence/round2/`。本轮复用了此前已安装依赖，未声称完成干净联网安装。Node实测24.19.0、TypeScript5.9.3、Vite8.3.3、React19.3.0。

真实浏览器桌面/手机渲染、控制台、首次使用点击链路与跨标签并发仍受环境阻断。HTTP200、SSR或Node测试均不能替代这些门禁。本轮发布决定保持 NO-GO。
