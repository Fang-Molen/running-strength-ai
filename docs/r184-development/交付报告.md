## 本轮源码实现

| 能力 | 实现及实际接入程度 |
|---|---|
| P1 能力画像 | 17 项指标适配器可调用；复用 R173 的掉速、CS、e1RM、力量课次数计算。五个竞技轴与恢复、执行、技术、比赛成绩、官方积分分开。现有复盘自动提供已保存分段、力量组次和恢复事实；其他指标还需专用事实输入适配，不能从旧经验分或记录条数生成。 |
| P2 探索任务 | 从同一复盘最多两项假设生成观察指标、支持/削弱条件及停止条件；可接收有批准来源、版本、目的、阶段、假设关联的课程。缺少唯一有效批准课程时只补记录，不新增剂量。 |
| P3 历史修订 | 沿用原追加日志，保留完整来源依赖和单项假设状态。显式事实更正可撤回相关解释；同协议、绑定来源的新观察经确认可支持或削弱。界面增加证据复核入口。缺失、普通反馈点击和单次反向表现不自动当反证。 |
| P4 周期管理 | 读取原计划目的、已确认阶段、比赛日期和优先级；生成 HOLD 或待确认的已批准课程重复观察候选。不推定周期，不改正式计划。 |
| P5 技术/力量 | 测量事实、动作观察、生理解释分层；步频/GCT 不代替氧耗经济性，e1RM 不证明跑步迁移。 |
| P6 效果验证 | 增加发生/记录/预测/训练与留出验证时间检查。没有可靠预测模型，精确成绩始终为空。能力图和间歇合计不输出 PB。 |

离线短答与详细复盘现在共用相同的解释和反证，并按事实、目的、解释、不确定性、下一次观察组织文字。旧经验分保留原数据，展示入口不再把它们当作有效能力分，也不再据此推算“今天可用能力”。没有增加大模型、服务器、向量库或新依赖。

R182 提供 **0 项已批准常模**，当前五维分数均为 null。评分公式、同协议观测变化、适用 SEM 下的 MDC95 和独立目标进度已编写；不代表已获科学验证或所有入口已连接。R182 的 SPD01/02 输出为 m/s 却标记 lower，本实现按速度公式改为 higher；SEN03 服从 STD-06 的情境性要求，不照表中 lower 直接评优劣。未启用任何候选阈值。

## 仍存在的限制

1. 第二阶段功能、界面、刷新持久化和零外联尚未运行验证，不能宣布集成验收完成。已有旧测试可能仍期望展示经验分、或仅凭普通反馈削弱判断，后续应核对产品合同后更新相应预期，不能降低安全断言。
2. 本次收到并读取的是 R182、R184；R182 继承了 R181 指标。当前未找到 R174—R181、R183 的完整独立包，不能宣称已完整接收其全部 P1—P6 算法。
3. 当前附件未找到原始 Garmin/FIT 导出 ZIP。R184 是案例转述/整理数据；其附带“16 PASS”是作者参考脚本结果，不是本轮 App 测试。没有运行该脚本或拿真实案例跑 App。
4. Garmin 只新增“已解码活动→待审阅候选”的纯函数接口，保留原始距离、圈序、平均/最高心率、计时/经过时间、两级休息及未定位休息。不含 FIT 二进制解析器、不自动导入。活动与确认训练课次分别计数；不同身份/设备/协议不合并。
5. LT、VO2、CMJ、正式比赛结果等尚未有完整事实采集页面；批准课程库尚未向新接口提供批准回执。故默认呈现现有事实和观察任务，不自动补出指标或课程。
6. 原有仅时长聊天的运动分类、聊天轮间休息/心率事实适配、本课各 Component 教练意图绑定仍需单独补齐；本轮没有用新 Garmin 接口掩盖这些旧缺口。历史失效记录若仅消失而没有明确撤回事件，新逻辑保留待验证，不擅自撤回。
7. 常模、维度合成、官方积分表、研究队列去重、质量标签、精确预测、目标编辑页面及完整历史分数重算仍未具备。逐项见 R182 的 17 指标与 26 标准范围表。
