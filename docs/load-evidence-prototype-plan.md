# 跑力负荷与曲线验证计划

目标：基于既有 EvidenceSnapshot 制作可复算的每日分项负荷候选原型，不生成疲劳分、不修改课表。

1. 使用现有事实与 `trainingDose`，按运动员、时区与发生日期生成每日跑步距离、已完成力量组数与整课 RPE 负荷。未知数据及数据覆盖明确标出。整课评分仅在口径为 CR10、整课时长可用且同一 occurrence 不重复时计算；冲突或混合课不可安全拆分则拒绝计算。
2. 按证据 id/版本列出依赖，重建可响应修订；不同来源重复、跨日归属和未确认记录必须在权威投影中核验，不从原始输入盲加。
3. 合成样例先验证已知数值、缺失、同课混合、其他运动员及更正后重算。对照现有测试与类型检查，记录未覆盖部分。
4. 完成证据与交付说明；原型不会连入问答或 UI，待范围、真实数据链与独立科学有效性验证后接入。
