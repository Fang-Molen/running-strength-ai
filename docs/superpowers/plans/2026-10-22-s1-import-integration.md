# S1 导入与统一同步窗口衔接

基线：用户上传的 `fangkun-s1-精简源码.zip`，包内目录 `fangkun-v89.10.9/`。

## 已授权的范围

沿用当前页面风格及统一设备同步窗口。保留 S1 的原始证据、人工更正、教练和健康趋势更新。按现有数据入口核对导入，不进行线上部署、真实平台授权或付费模型调用。

## 实施步骤

1. 比较 S1 与上一版统一窗口源码；仅补充实际遗漏或修复可复现的衔接问题。
2. 为缺失、未佩戴、冲突及撤回状态提供显式选择；默认不选。保存计数与保存内容使用同一份选择结果，已选读数保留其原始证据历史。
3. 人工更正追加新修订并保留原始事实；健康投影显示最新更正及来源。覆盖连续更正、日期更正、Apple 聚合和旧文件重导入场景。
   - 更正被拒绝时复位数值草稿，保证显示值与实际保存值一致。
   - 批次保存复用已有证据索引，避免每条读数重新扫描全部历史；保留写入失败、碰撞和归属保护。
4. 在读取、识别、预览和保存边界绑定运动员；切换身份或卸载后丢弃旧异步结果。
   - 原始状态和超过 200 条的活动可以继续展开核对。
   - 授权回调优先进入统一窗口；一次启动只处理一次，防止快捷导入参数和 React effect 重放触发第二个窗口。
5. 使用合成数据完成针对性回归、应用类型检查及开发/构建预览验证；保留现有已知限制的准确说明。
6. 核对完整源文件清单、ZIP 校验和与基线差异，交付完整源码压缩包。

## 验收要点

- 未勾选的状态不落盘；有效读数附带的原始历史不丢失。
- 更正后的读数、来源、日期与健康投影一致，不改变原始证据。
- 旧运动员的解析任务不能进入新运动员的预览或存储。
- 原有同步、授权窗口、健康日期导航和页面风格保持。
- 不将模拟验证描述为真实手表连接、真实健康读取或已部署。
