# 1B / 1C 本轮接线与验收

基线 92632540c8cd42267461d42403786bec2a2281eb，2026-10-28。本轮只使用合成档案、隔离 SQL 和假模型。前后端内部一致性验证不能证明客户端事实真实性，也不代表真实模型或专业判断通过。

本轮修改：

- 本人口语状态、混合本人/第三人问题和“我明天呢”追问可接续已有语境；独立知识问题保持原有资料边界。
- `context-period.ts` 按用户时区解析日期、去年/今年、跨年及比较范围，先选择所问年份，再做预算分配；没有记录时明确覆盖不足。十五条今年记录不再挤掉相关去年记录。
- `context-fields.ts` 将长字段分段保留，单字段遵守 V2 的 256 字限制。超过记录字段预算时显式标注不完整、遗漏数量与全文摘要；不静默丢弃尾部。服务端重新拼接限制字段，残缺限制不得作为训练许可。
- `online-handoff.ts` 传递候选的观察条件、支持/反证、禁止执行和版本依赖，安全约束独立表达。七天外相关基线及反证按依赖纳入；预算无法承载完整依赖时撤下相应分析并说明。
- 比较与改课同句分别进入对比及 R5 提案，保留差异预览和显式确认；不直接写正式课表。
- 同来源缓存冲突经现代分析和旧日汇总接线，当前冲突说明不伪装为历史已知观测。
