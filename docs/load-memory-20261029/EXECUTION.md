## 执行顺序与验收

### 1 数据及计算口径（先解决）

- 明确整课评分、评分采集时刻/量表、完整时长口径；缺少证明时仅候选，禁止用最后一组RPE代替整课。
- 当前结束时间晚于分析时间会拒绝AU；但结束时间为空仍可计算，需区分已确认完成但缺结束时间的导入与未结束的原生训练，不得直接将两者混为一类。
- 整课 occurrence 与跑步/力量 component 分层，整课AU只算一次；独立课有独立评分才能分别算。未知或有冲突保留未知。
- 跑步同时显示已知距离和完整性；力量按动作、版本、重量口径、单侧/双侧、次数/时间分别汇总，保留RIR/RPE和休息缺失。不可只用组数推断刺激。
- 测试：未结束、末组RPE、完整课/移动时间混淆、重复同步、多设备冲突、混合课、哑铃每手/总重、跳过/未知、补录/撤销/更正。

### 2 统一范围与日期

- 旧趋势按北京时间，新明细按分析上下文时区；统一为明确的用户日历口径，并保留来源原时间。跨午夜课明确归属策略，不重复计数。
- 历史筛选在查询/投影阶段就明确范围，禁止先默认取近期90天后声称查过更旧日期。区间与离散日期分别解析；先修端点遗漏，再做历史曲线。
- 验收跨年、闰日、上海/UTC跨日、晚同步、开始日与结束日、区间中间记录、两个离散日期及空范围。

### 3 汇总与增量更新

- 日周汇总记录覆盖、缺项、来源版本、算法版本、时区及读取截止时刻；已确认休息才为零。
- 新增、更正、撤销、删除、重复及晚同步触发相关日和依赖窗口失效；滚动指标重算到最新受影响点，失败标待更新。不要简单把新值加到旧总量。
- 缓存按运动员隔离；更换用户立即清理可见旧结果，异步旧响应不得回填。当前页面storage监听不能替代完整身份变化管理。
- 验收增量与全量参考重算逐日一致（覆盖删除/回放），重复处理幂等，未来才录入的信息不污染历史判断。

### 4 分层存储与检索

- 原始记录、日周/月摘要、关键事件及个人参考分层；默认不删除原始训练。
- 检索权重与训练负荷及生理模型时间权重分开；0.3/0.7只可作为待评估检索配置，不是科学强度系数。
- 用户指定日期/课次优先；汇总必须含完整合格数据，不只挑高权重训练；反证、疼痛、来源冲突与覆盖缺项有保留位置。
- 首次建立/迁移可读取完整授权范围；后续可用索引和缓存按受影响范围更新，避免每次问答扫描全部历史。

### 5 UI与问答闭环

- 训练详情显示分项和补项入口；桌宠补反馈绑定明确训练；健康页显示曲线、覆盖和更新时间；方坤引用同一份汇总与来源。曲线点击可查当日依据和训练，明确未更新与错误状态。
- 当前新旧模块分别读不同投影，需统一；不能只保留两个口径不同的面板并排显示。
- 首屏简洁摘要，展开再看数值、公式与来源；未知画断点或明确缺失标记，不当零；旧答案在证据变化后提示重审。
- 浏览器实际完成保存→刷新→读取→更正→重载→切人，检查手机窄屏、长文本、展开、键盘及安全区。不用强制点击掩盖遮挡。

### 6 研究与效果界限

- 现有研究仅初步查证，继续核对全文/适用人群/协议。将描述性计算、个人相对变化、生理推断分开。
- 未建立个人基线的维度明确未建立；不能因固定天数到达就宣布准确。换设备或持续恶化时不能悄悄吸收为正常。
- 缺乏足够依据时照常回答已知事实并说明缺什么，不制造完整疲劳结论，也不一概拦截普通问题。保持已有联网默认策略。
