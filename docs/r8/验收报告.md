## 本轮修复

1. 周次问题允许由用户明确提供的日期绑定到已选训练，无法可靠映射时才核对；不从 ID 或当前计划猜周次。修正均值配速、否定范围、恢复时钟和历史/当前 RPE 的部分误拒。
2. 已确认导入以只读独立课次进入 brief、正式证据、模型请求和本地回答；不重复写入训练事件。按运动员和确认时间隔离，删除后退出证据。导入来源保留为用户自报，不能变成已核实设备事实。
3. 力量实际重量、次数和持续秒数进入正式证据与代码计算；计划值不填补实际值，跳过组不计完成量。重量/次数更正引用更正来源，旧事实失效；kg×次只表达机械记录量，不声称是生理负荷。
4. 主观恢复、酸痛正式入层；酸痛不自动当疼痛。24H/48H 恢复保留不同端点，同一端点冲突不自动择一。实跑发现训练结束 RPE_RECORDED 被白名单遗漏、连续跑完成段未入层，两处均修复并补回归。
5. 逐段平均心率新增数值与测量方法，绑定已记录段来源后才进入正式证据。协议字符串不能提供心率；未生成生理解耦、心率漂移或疾病判断。
6. 身体指标和设备证据作为只读上下文接入。RHR/HRV 仅在设备、方法、时刻、来源一致且日期不重复时作描述性比较；缺少元数据不补猜。设备库只传确认后的有限读数，不传原图或原始 OCR，不猜所属课次。
7. 目标偏好及已接受候选计划作为上下文接入；候选不变成实际成绩或已应用课表。候选接受路径调用既有计划治理函数，阻断需核对的候选。没有新增自动写计划或权限弹窗。
8. 联动后发现共享目标上下文让跨课次比较被误拒，已修复；上下文引用仍不能替代每个课次自己的证据引用。保留原生产守卫、急症/疼痛保护与费用开关。
