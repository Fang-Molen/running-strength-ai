# 自我复盘：防止新方案引入新漏洞
| 风险 | 本方案处理 | 仍需证实 |
|---|---|---|
| 类型标签可被模型伪造 | host校验语义与来源，标签只是候选 | 讽刺、否定、隐式建议等泛化 |
| 修复删除条件造成放行 | group/dependency原子校验，修复后再审 | 跨段指代、多条件、长上下文 |
| 任务完整度被模型自报欺骗 | task契约由请求生成，独立核最终正文 | 复杂多意图和合理澄清的裁决 |
| 所有数字放开导致虚构剂量 | 事实/计划/建议分别审核、专业适用检查 | 专业策略的科学依据与适用人群 |
| 风险规则过宽导致无法交流 | 动作/时间/部位范围分开，知识可答 | 症状严重程度及行动冲突的专业审核 |
| 基线/疲劳数值产生假精确 | 非本包开发指标；无验证不宣称精准 | 真实长期效度、设备差异仍是独立任务 |
| 缓存保留撤回限制和旧更正 | revision/策略/授权/检索状态纳入缓存 | 并发更新及退出账号测试 |
| 网络常开变成“假检索” | 设置与执行状态独立 | 真正检索链路与来源质量 |
| 数据库写入与回答不一致 | 回执、幂等、提交前权限、对账 | 断网/超时/重复提交真实端到端 |
| 宿主计算绕过过滤 | 合成后统一校验，保存公式链 | 确定性计算器本身的更多边界 |
| 评估器自证满分 | 缺项不默认PASS、公开回归与盲测分开 | 本包工具不验证人工填报真实性 |
| 修复增加成本/时延 | 最多一次、增量包、全尝试统计 | 预算能否兼顾任务和专业质量 |
| 新旧接口双路径漏校验 | 控制器两条路径均适配，共享最终门 | 实际最新源码所有入口清点 |
| 输出流提前展示危险建议 | 验证语义组后流式展示 | 实机渲染时序和回滚行为 |
| 只修后处理掩盖上游缺资料 | 上游事实包/连续更正/来源先修 | 真实设备导入和摘要更新全链路 |

## 本次特别保留的待办
1. 未对 Q08 的运动风险判断做专业签审。本包不使用它证明“运动安全判断已合格”。
2. 本包不是所有品牌手表适配验收；只制定跨来源/单位/时间/重复记录对回答的校验要求。
3. 不能凭本包给整软件重新打百分制总分。需完成V3全能力测评，再按固定权重和未测项披露给分。
4. 新机制先shadow：同一冻结输入并跑旧/新门，差异留审；shadow不影响用户原有输出，不等于新门已上线。若旧门存在关键安全缺陷，应禁用相应高风险功能而非继续无保护灰度。
5. 灰度仅限已验证低风险能力，并有可回退策略版本；“回退”不能回到已知不安全版本，可回到经过校验的保守答复。
6. 真实医学/运动专业策略需由对应研究与审核任务提供来源、适用条件及版本；本次聚焦软件校验设计，没有新增未经检索支持的科学阈值。
